Places API (New) integrasjon

Denne siden demonstrerer hvordan MATS-OS kan bruke Google Places API (New) direkte fra frontend for å hente placeId og deretter Place Details (New).

Søk etter sted

Hvordan dette funker

Places API (New) • Text Search + Place Details
Steg 1: Få placeId

Først kaller vi places:searchText med en textQuery. Dokumentasjonen sier:

“Once you have a place ID, you can request more details about a particular establishment or point of interest by initiating a Place Details (New) request.”

Vi ber om places.id og places.displayName via X-Goog-FieldMask, slik at vi får akkurat det vi trenger uten å trigge unødvendige SKUs.

Places API (New) • FieldMask
Steg 2: Place Details (New)

Når vi har placeId, kaller vi:

https://places.googleapis.com/v1/places/PLACE_ID

Dokumentet sier: “Specify the list of fields to return in the response by creating a response field mask… If you omit the field mask, the method returns an error.”

På denne siden ber vi om: id,displayName,formattedAddress,location,types,websiteUri,rating,userRatingCount for å vise et kompakt, MATS-OS‑style POI‑kort.

Transit • Innovators
Videre: transitStation, FRAM og kollektiv

Places API (New) støtter også transitStation, som gir linjer, farger, ikoner og Stop ID for kollektivknutepunkt.

Du kan senere utvide denne siden til å hente transitStation og bygge en MATS-OS Transit Mode med FRAM, Ruter, Skyss og mer.
